Overview

Birch · Slowed Visualizer is a minimalist, single-file browser web application created by P1faG0r. It allows users to drop in any audio file, apply real-time Slowed + Reverb audio effects, and enjoy an atmospheric canvas visualizer with customizable color themes and birch tree aesthetics.

Key Features

🎧 Real-time Audio Processing:

Adjustable playback speed (Slowed effect from 0.50x to 1.10x with pitch shifting disabled/enabled dynamically via Web Audio API).

Built-in Reverb effect slider powered by custom impulse response convolution.

🎨 Interactive Audio Visualizer:

Procedurally generated radial spectrum analyzer that reacts to live audio frequencies and bass hits.

Organic birch trunk textures, custom center disc, and dynamic particle effects.

🌈 Customization & UI:

7 preset color palettes (Birch, Ice, Sunset, Neon, Mint, Lavender, Blood) plus a custom color picker.

Editable song title with automatic local storage saving per file.

Clean / Ambient mode (hide all controls with a keypress or double-click for immersive listening).

🚀 Zero Dependencies: Pure vanilla HTML5, CSS3, and JavaScript (Canvas 2D + Web Audio API). No external libraries, node modules, or build steps required.

Controls & Shortcuts

Drag & Drop / Select: Drag any .mp3, .wav, or supported audio file into the window or use the file picker button.

Spacebar: Play / Pause audio.

H key: Toggle Clean Mode (hide/show control UI).

F key: Toggle Fullscreen mode.

Double Click: Double-click the canvas background to toggle UI visibility.

Title Editing: Click on the title at the top to type a custom track name (saves automatically).

How to Run

Download or clone the repository.

Open Music(Temp Changer).html in any modern web browser (Chrome, Firefox, Safari, Edge).

Select or drag your audio file into the player!

Обзоp

Birch · Slowed Visualizer — это минималистичное одностраничное веб-приложение, созданное P1faG0r. Оно позволяет загружать любые аудиофайлы, применять в реальном времени эффекты Slowed + Reverb и наслаждаться атмосферным визуализатором с настраиваемыми цветовыми темами и эстетикой берёзовой рощи.

Основные возможности

🎧 Обработка звука в реальном времени:

Регулировка скорости воспроизведения (эффект Slowed от 0.50x до 1.10x) с изменением тональности через Web Audio API.

Встроенный регулятор Reverb (реверберация), созданный с помощью конвольвера и импульсных характеристик.

🎨 Интерактивный визуализатор:

Процедурно генерируемый радиальный спектроанализатор, реагирующий на частоты и басы.

Текстуры берёзовых стволов, динамические частицы и центральный берёзовый спил.

🌈 Кастомизация и интерфейс:

7 готовых цветовых палитр (Береза, Лёд, Закат, Неон, Мята, Лаванда, Кровь) + возможность выбора любого произвольного цвета.

Редактируемый заголовок трека с автоматическим сохранением названия для каждого файла в localStorage.

Режим «Чистый экран» (скрытие элементов управления для максимального погружения).

🚀 Без сторонних библиотек: Написано на чистом HTML5, CSS3 и JavaScript (Canvas 2D и Web Audio API). Не требует сборки или установки зависимостей.

Горячие клавиши и управление

Перетаскивание (Drag & Drop): Перетащите .mp3 или .wav файл прямо в окно браузера или используйте кнопку выбора файла.

Пробел (Space): Воспроизведение / Пауза.

Клавиша H / Р: Скрыть или показать интерфейс управления.

Клавиша F / А: Переключение полноэкранного режима.

Двойной клик: Клик по фону скрывает/показывает панель управления.

Редактирование названия: Нажмите на название трека вверху экрана, чтобы изменить его (сохраняется автоматически).

Как запустить

Скачайте или клонируйте репозиторий.

Откройте файл Music(Temp Changer).html в любом современном браузере.

Выберите или перетащите аудиофайл и наслаждайтесь!
